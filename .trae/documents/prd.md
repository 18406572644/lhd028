## 1. 产品概述

电影盲盒推荐平台是一个以复古影院为视觉风格的沉浸式电影推荐应用，通过"盲盒"机制为用户带来惊喜式的电影发现体验。用户可以根据个人喜好生成专属电影盲盒，打开后获取随机推荐影片，并结合观影记录、评分评论、盲盒收藏与好友分享功能，打造趣味社交的电影探索之旅。

- 目标用户：热爱电影、喜欢探索新片的年轻群体和影迷社区
- 核心价值：用游戏化盲盒机制打破"选片困难"，让电影发现变得充满惊喜和仪式感

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 用户名注册/登录 | 浏览电影库、生成盲盒、观影记录、评分评论、盲盒收藏、好友分享 |
| 管理员 | 后台指定 | 电影数据管理、用户管理、数据统计查看 |

### 2.2 功能模块

1. **首页**：复古影院风格 Hero 展示、盲盒入口、热门推荐、最近活动
2. **电影库**：电影列表浏览、分类筛选、搜索、电影详情
3. **盲盒生成**：选择偏好标签、生成盲盒、开盒动画、盲盒结果展示
4. **盲盒收藏**：已收藏盲盒列表、盲盒详情回顾、取消收藏
5. **观影记录**：观影历史列表、观影状态标记、记录统计
6. **评分评论**：电影评分、发表评论、评论列表、评分分布
7. **好友分享**：生成分享链接、分享卡片预览、好友互动
8. **数据统计**：观影统计图表、偏好分析、评分分布、活跃度

## 3. 核心流程

### 3.1 盲盒生成流程
用户进入盲盒页面 → 选择偏好标签（类型、年代、评分） → 点击"生成盲盒" → 系统根据偏好随机筛选电影 → 播放开盒动画 → 展示推荐结果 → 用户可选择收藏或分享

### 3.2 观影记录流程
用户浏览电影 → 标记"想看/在看/已看" → 系统记录观影状态 → 对已看电影评分评论 → 记录出现在观影历史中

### 3.3 好友分享流程
用户选择盲盒/电影 → 点击分享 → 生成复古风格分享卡片 → 复制链接 → 好友打开链接查看内容

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深棕/暗金（#2C1810、#D4A574）+ 猩红点缀（#C41E3A），营造老式电影院氛围
- **辅助色**：奶白（#FFF8F0）、暗橙（#B8602A）、烟灰（#4A4A4A）
- **按钮风格**：圆角立体按钮，带浮雕效果和暗金色边框，hover 时发光
- **字体**：标题使用衬线体（Playfair Display / Noto Serif SC），正文使用无衬线（Noto Sans SC）
- **布局风格**：卡片式布局，圆角暗金边框，胶片纹理背景
- **图标风格**：复古线条图标，配合胶卷、放映机、爆米花等电影元素
- **特效**：胶片颗粒噪点叠加、复古色调滤镜、开盒闪光动画、卡片翻转动效

### 4.3 响应式设计

- 桌面优先设计，最小支持 1024px 宽度
- 平板适配：768px-1024px，卡片网格从4列变2列
- 移动端适配：<768px，单列布局，底部导航替代侧边栏
- 触控优化：按钮最小点击区域 44px，手势滑动支持

### 4.4 动效设计

- 页面进入：淡入+微上移动画，stagger 延迟 100ms
- 卡片交互：hover 时微缩放+阴影加深+金色边框高亮
- 盲盒开盒：3D翻转 + 粒子爆炸 + 金光闪烁
- 数据图表：数值从0动画递增，图表元素逐个绘制
- 页面切换：胶片卷轴过渡效果
